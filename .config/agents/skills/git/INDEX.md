# Git Man Page Index

## `git`

Entry point for Git invocation, global options, command categories, repository concepts, environment
variables, security notes, and links to broader docs


## `gitcli`

Command-line syntax conventions, option parsing, revision and path ambiguity, pathspec placement,
pager behavior, aliases, and scripting expectations


## Subcommands

For command-specific behavior, consult the subcommand manual page directly.
E.g., `git-checkout`, `git-diff`, `git-rebase`, `git-reset`.


## `giteveryday`

Practical minimum command set for individual developers, contributors, integrators, and repository
administrators


## `gitglossary`

Definitions for Git terms such as refs, index, pathspecs, remotes, object names, upstream branches,
and working trees


## `gitrevisions`

Revision naming syntax, ranges, ancestry selectors, reflog selectors, refname disambiguation, and
commit-set notation


## `gitattributes`

Per-path attributes controlling diff, merge, text normalization, filters, archive behavior, and
generated files


## `gitignore`

Ignore pattern files, precedence, pattern syntax, negation, directory matches, and common ignore
behavior


## `git-config`

Reading and writing Git configuration, config file scopes, value types, conditional includes, and
built-in configuration variables


## `githooks`

Client-side and server-side hook names, invocation points, arguments, environment, and bypass
behavior
